# unreal.show

Static site for UNREAL, served by GitHub Pages at https://www.unreal.show.

- `index.html` – the whole site (CSS/JS inline, schema.org JSON-LD in the <head>).
- `cast/` – put the six approved portraits here as `sienna.png`, `marcus.png`, `pru.png`, `julian.png`, `ro.png`, `atlas.png`.
- `CNAME` – tells GitHub Pages the custom domain (www.unreal.show).
- Votes go to the "UNREAL website votes" Google Form on unreal.show.cast@gmail.com (fields: poll, choice, voter). Count the latest row per voter.
- Trailer: set `TRAILER_YT` in index.html to the YouTube video ID to replace the placeholder.
